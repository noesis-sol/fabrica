  this machine or one over SSH, and install or update its engine there through main (`fabrica:check-engine`,
  `fabrica:install-engine`, the host and consent decoded by the preload and again by main), from the packaged
  app's signed release folder where it carries one, else from Fabrica's releases, staged under the app's
  temp folder. A packaged app installs its own version, a development build the latest release. ssh asks
