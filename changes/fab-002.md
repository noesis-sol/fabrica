- The gate reads more forms of a write, wherever it lands (spec §12.6, §20.2): `sed -i.bak` and BSD's `sed -I`, and a
  script attached (`sed -i -es/a/b/ f`), which left its first file unread; `-t`'s folder attached or in a group
  (`cp -t/tmp/x a`, `mv -ft /tmp/x a`), and any option's value in a group (`mkdir -pm 755 x`); `find`'s `-fprint`,
  `-fprint0`, `-fprintf` and `-fls`; `git init`'s path and `--separate-git-dir`; `sort -o`; and `busybox` and `toybox`,
  read as the command they run, with `--install` asked.
- A `$"…"` word reads as its `"…"`. A `$'…'` word with an escape that doesn't stand for itself (`$'\x6fut'`) is known
  only when it runs, so where it names a command or a path the gate asks.
- A Pi file tool's `file://` URL with no path on this machine (`file://host/x`, `file:///a%2Fb`) asks, where it threw
  and blocked the call with a poor reason.
- `ln -s ../a.ts sub`, where `sub` is already a folder, reads the target from `sub`, where `ln` makes the link: no
  ask for a link staying inside, and an ask for one through a folder link that lands outside. `-T` and `-n` read
  the last operand as the link itself, as `ln` does.
