- The console has keys for the permission request the attention column shows first: `Y` approves it once,
  `W` allows it for this run, `N` opens its refusal's note. They answer only that request, only while its
  buttons are drawn, and only 500 ms after it was first drawn, a guard on the injected clock that starts
  again whenever the request they would answer changes (§15.1, §18.5, H62). They are commands of the
  console's one list, so the key help and the palette show them, and that card's buttons carry their caps.
