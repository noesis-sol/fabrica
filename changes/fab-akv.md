- `fabrica serve` runs projects: the daemon is given its run hosting, Pi in RPC mode on the distribution's Node
  with the first-party extension (in a dev checkout, node_modules' Pi and the built extension), reaching its
  models through the model proxy, which sends each known provider's calls on with the credential in the
  engine's secret store; processes on the host, their limits counted in time awake; records dated in the
  host's zone; each worker's and check's share of the cores under `machine_workers`, the workers at
  `worker_nice`, both read as the engine starts. A missing agent part, or a secret store or model proxy that
  can't open, has every run refused, saying why. Until the maintainer answers them, the gate's permission
  requests are answered as the project's `permissions` says: `full` allows, the other levels refuse.
