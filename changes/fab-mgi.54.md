- History under the sidebar's All projects scope shows every project's events: the app watches the events of
  each project's run going (its sidebar row's Running or Waiting run) and merges them newest first by the
  moment each was recorded, times in different zones compared as instants, each project's own order kept.
  Each row carries its project's chip (its colour and two-digit index, as the sidebar draws it) between the
  dot and the line; a project's own scope shows its events alone, unmarked. The Model keeps each project's
  events apart (`ProjectEvents`), from its stream's first snapshot.
