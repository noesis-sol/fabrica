- Console keys for the run controls (spec §13.10, §18.5): `R` opens Start run's modes (each mode also a palette
  command), `S` drains or undrains the scoped project's run, `X` asks to stop it and `X` again stops it, `Esc`
  closes Start run's modes or field and keeps a run running. They are in the console's command list, its key
  help and its palette only while the stats row offers their buttons enabled (`Stats.offers`).
